# 玩家可见文案约束

这些约束用于防止游戏内文本出现开发视角，保持《道痕归墟》的世界观沉浸感。

## 核心原则

- 玩家看到的所有文字，都应像来自玄曜界、天机命盘、道纪札记或应劫者记录。
- 不要描述“我们做了什么功能”，要描述“玩家现在可以经历什么、获得什么、面对什么”。
- 不要使用开发、产品、数据配置、实现细节、调试和社区黑话。
- 如果必须展示规则，使用游戏内命名：战诀、洞天秘境、归墟天阶、神游历练、道痕记录、法器、道纪遗宝。

## 禁用表达

- 开发数据库、开发模式、开发者、调试、TODO
- 数据包、接入、实现、MVP
- 推荐 BD、BD 建议、构筑覆盖
- Codex 或任何工具名

## 推荐替换

- 推荐 BD -> 流派参悟、修行思路、战诀搭配
- 开发数据库 -> 万象图鉴、天机图录
- 数据包 -> 赛季、道纪、天机札记
- 接入机制 -> 机制开放、道纪生效、玩法开启
- 道痕建议 -> 道痕记录、修行提示

## 自动检查

构建前会运行：

```sh
pnpm run check:copy
```

如果 `src/data` 或 `src/ui` 中出现禁用表达，构建会失败。新增玩家可见文案时，先用上面的世界观说法改写。
